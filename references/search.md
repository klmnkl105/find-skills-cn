# GitHub 搜索参考

只使用 GitHub 原生搜索和 GitHub 自身的数据源，例如仓库页面、GitHub API、GitHub CLI 和 GitHub 提供的原始文件。可按需要搜索仓库、代码、README、`SKILL.md`，并自行调整关键词、语种和检索深度；不使用其他网站、搜索引擎或第三方索引。

按用户目标判断资源类型，查阅足够的 GitHub 资料确认其功能和匹配度。用户明确要 Skill 时确认能定位到具体 Skill；查找其他资源时不强制要求 `SKILL.md`。

遇到限流或故障时，若权限允许且工具可用，可改用其他 GitHub 原生入口；若仍不可用，说明受限并区分搜索失败与无匹配结果。GitHub star 属于仓库；Release 资源下载数有具体资源范围，不等同于总安装量。缺少可靠数据时省略。
